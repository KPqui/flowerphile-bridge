1 Install or update the firmware

Plug the bridge into this computer and press the button. Pick the port that appears (often “USB JTAG/serial debug unit”).

This browser can't talk to USB. Use Chrome or Edge on a computer. USB needs a secure page (https).
  • First install: say yes to “erase”. Updates: say no, so the settings stay.
  • If it can't connect: hold the small side button ~2 s until a green light shows, release, try again.
  • When it's done, close that dialog before step 2 (only one thing can use the port at a time).

3 Sensors it hears

Every Govee H5074 in range. The ID is the last 4 characters of the sensor's name (Govee_H5074_ABCD) — write it on each sensor. Strongest signal = closest.

4 Settings

Sent straight down the USB cable and stored on the bridge only. This page makes no network requests with them, and the bridge never sends the key back. Leave the key empty to keep the current one.

5 Status

Light: green fine · amber no Wi-Fi/time · purple no sensors heard for 30 min · red key/repo problem or pushes failing · blue needs settings. Hold the front button to see it; hold 5 s to push now.
